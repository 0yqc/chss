# `chss`

`chss` is a container repository for different chess engines I coded.

# `chss/kotlin` - Alpha-beta pruning Chess Engine (Kotlin)

`chss/kotlin` is a [alpha-beta pruning](https://en.wikipedia.org/Alpha-beta_pruning) chess engine, coded in Kotlin. This is the engine coded during [Hackclub Midnight](https://midnight.hackclub.com/).

# `chss/manual`

`chss/manual` is the first chess engine I started in PYthon, but never finsihed. I tried coding everything myself without any libraries.

# `chss/py-chess`

`chss/py-chess` was the first attempt of using a library. I used the `py-chess` library and coded in Python.

# `chss/bulletchess`

`chss/bulletchess` changed to the faster `bulletchess` library, still in Python.
